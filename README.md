# 🦷 Sakthi Dental Clinic - Landing Page

A professional, conversion-focused landing page and Single Page Application (SPA) built for the **ShadowFox Intermediate Level Task**. Designed based on a comprehensive client brief to project trust, hygiene, and warmth for women, children, and families in Hosur.

## 🎯 Design & Architecture Decisions
* **Color Psychology:** Shifted from generic colors to a clinical palette (Medical Sky Blue & Calming Teal) with soft cyan surfaces to reduce visual fatigue and build subconscious trust.
* **SPA Routing:** Implemented custom vanilla JavaScript routing to switch between Home, About, Treatments, FAQs, and Contact views instantly without page reloads.
* **Conversion Funnel:** The main landing page sequentially guides users through the Hero banner, Trust features, Core Services, Transparent Pricing (added for conversion strategy), Testimonials, and finally, a Lead Capture Form.

## 🌟 Features
* **Dynamic Hero Section:** Welcoming headline with quick-action Call-To-Action (CTA) buttons for appointments and emergency support.
* **Transparent Pricing Packages:** A dedicated section highlighting consultation and treatment packages.
* **Comprehensive Treatments Gallery:** A neatly gridded display of 14+ dental procedures (e.g., Laser Dentistry, Implants, Orthodontics).
* **Interactive FAQ Accordion:** Custom JavaScript accordion to handle patient queries efficiently.
* **Lead Capture Form:** A dedicated appointment request form with simulated submission states and validation.
* **Fully Responsive:** Adapts perfectly from mobile screens to ultrawide desktop monitors.

## 🛠️ Tech Stack
* **HTML5** (Semantic structure & accessibility)
* **Tailwind CSS** (Rapid UI development, custom medical shadows, and theming)
* **Vanilla JavaScript** (SPA view switching, accordion logic, form handling)
* **FontAwesome** (Medical and UI iconography)

## 🚀 How to Run / Deploy
1. Clone the repository.
2. Open `index.html` in any web browser.
3. **Deploy:** This single-file project is completely deployment-ready. Drag and drop the folder into Netlify/Vercel or push to GitHub Pages for instant live hosting.
